# Impact Tracker demo

`impact-tracker-demo.html` is a self-contained, in-browser version of the app
for demos. It runs the same status rules as the real app on the example
project, and every screen and form works. Each visitor's changes are kept in
their own browser (localStorage); "Reset example data" restores the example.

It is published as a Claude artifact. To view it locally, wrap it in a basic
HTML page or open it through the artifact link. It is not connected to the
real app's database.
